How Automated Email Delivery Works
01

Sign Up for EmailJS

Go to emailjs.com → create a free account → connect your Gmail or any email service. Free tier sends 200 emails/month.

02

Create an Email Template

In EmailJS, create a template using variables: {{name}}, {{email}}, {{model}}, {{cheatsheet_content}}. Set the "To" field to {{email}} so it sends TO the user.

03

Add Your Cheat Sheet PDFs

Host one PDF per model on Google Drive (set to "Anyone with link can view"). Add each link to the MODEL_LINKS object in the script below.

04

Paste Your Keys

Replace YOUR_PUBLIC_KEY, YOUR_SERVICE_ID, and YOUR_TEMPLATE_ID in the script. The form will instantly send the correct sheet to each subscriber.
